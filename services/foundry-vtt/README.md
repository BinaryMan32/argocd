# Foundry VTT

One deployment of [Foundry Virtual TableTop][foundry-vtt] per licensed user.

Each deployment can host a game world which can be accessed by multiple users,
but must have its own purchased license.

See [Foundry Kubernetes Wiki][foundry-k8s-wiki] for deployment references.

[foundry-vtt]: https://foundryvtt.com/
[foundry-k8s-wiki]: https://foundryvtt.wiki/en/setup/hosting/Kubernetes
